Cách dùng

Từ máy sạch đến chạy script

Năm bước ngắn. Video hướng dẫn có thể gắn sau — hiện dùng checklist đúng luồng cài đang ship.

  1. Jailbreak iPhone

    Cần máy đã jailbreak iOS 14+ (MobileSubstrate). Dopamine phổ biến trên iOS 15–16; kiểm tra rootless /var/jb.

    Dopamine Sideloadly

  2. Thêm nguồn & cài AutoIOS

    Trong Sileo: Sources → + → dán raw.githubusercontent. Search AutoIOS, cài com.manhvip.autoios. Hoặc dùng lệnh SSH bên dưới.

    Tới nguồn Sileo Cài SSH

  3. Bật LAN & mở Studio

    Settings trên máy → bật LAN. Mở Auto IOS Studio (hoặc trình duyệt cùng Wi‑Fi tới http://<ip>:2000) với token 8 ký tự.

  4. Nhập license (tuỳ chọn)

    Free chạy được ngay, giới hạn 2 phút/lần. Premium: dán key HMAC trong Settings — bỏ giới hạn thời gian chạy.

    Xem bảng giá

  5. Viết Lua & Run

    Mở editor hoặc Flow Builder, Run trên máy active. Xem log realtime, Live View để theo dõi. Script lưu tại /var/mobile/Documents/autoios.

Studio / Web IDE trên LAN

Sau khi cài, bật LAN trong Settings. Trình duyệt cùng Wi-Fi mở http://<ip>:2000 kèm token 8 ký tự. App 0.4.14 trở lên mở đúng IP máy, không cần gõ URL.

Token nằm trong Settings và /var/jb/etc/autoios/token. API trừ GET /api/status cần Authorization: Bearer.

Chạm qua TrollVNC

Chạm trong View đi qua TrollVNC RFB, cùng đường với click. Không BKHID, không IOHID. VNC: cổng 5902, mật khẩu là 8 ký tự đầu của token.
